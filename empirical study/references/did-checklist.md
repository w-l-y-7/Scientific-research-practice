# DID 设计关键假设清单

对应 `CLAUDE.md` 第七节第 1、3、4 条 HITL 节点。第 1 节管识别设计，
第 4、5 节和 `regression-spec.md` 的主回归命令、聚类层级部分配套使用。

每一条都要在 `code/01_identify/` 的决策记录里留下检验结果。**没有检验结论的假设，
不能当作成立**——写「未检验」比默认它满足要安全。

## 1. 平行趋势假设

- 条款：若无政策干预，处理组与控制组的结果变量应沿相同趋势演化
- 检验：事件研究图观察处理前各期系数是否显著偏离零
- 陷阱：处理前样本期过短（<3 期）无法有效检验

## 2. 无预期效应（No Anticipation）

- 条款：政策宣布到实施之间，处理组行为未提前调整
- 检验：事件研究图中 -1 期（政策前一期）系数是否显著
- 陷阱：渐进 DID 中不同处理组宣布期差异可能掩盖预期效应
- 陷阱：**若事件研究图把 -1 期设为基期，该期系数被机械置零，这一检验就失效了。**
  要么把基期挪到更早（如 -2 期或更前），要么不设基期、直接看全部领先项

## 3. SUTVA（无溢出效应）

- 条款：一个单位的处理不影响其他单位的结果
- 检验：地理相邻州之间的就业流动、溢出回归
- 陷阱：劳动力在州界自由流动时溢出不可忽视

## 4. 渐进采纳的负权重问题

- 条款：TWFE 在处理时点异质时可能赋予某些处理组负权重
- 检验：用 Callaway-Sant'Anna（`did::att_gt`）或 de Chaisemartin-d'Haultfoeuille
  估计量对照，并报出两者系数差
- 命令：`did::att_gt()` + `did::aggte()` 对 `fixest::feols(y ~ d | id + t)`
- 陷阱：传统 TWFE 系数可能与真实 ATT **符号相反**，而不只是大小有偏

## 5. 聚类层级

- 条款：标准误聚类需与处理变量的变异层级匹配
- 检验：`cluster = ~state_id` 是否与处理层级一致
- 命令：`did::att_gt(..., clustervars = "state_id")`；`fixest::feols(..., cluster = ~state_id)`
- 陷阱：聚类单元过少（<30）时 Wild Bootstrap 更稳健
- 陷阱：`feols` 不写 `cluster` 不会报错也不会警告，只是安静地给你另一套标准误
  （见 [regression-spec.md](../.claude/rules/regression-spec.md) 的默认值表）
