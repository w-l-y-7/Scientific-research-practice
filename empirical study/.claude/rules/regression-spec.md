# 回归规范默认值

对应 `CLAUDE.md` 第七节第 3、4 条 HITL 节点。这里写的是**默认值**。

默认值不等于已确认：走到那两个节点仍须停下来等研究者拍板。这份清单的作用是省掉
每次从零讨论的时间，不是替代确认。最终规范以确认版本为准，不照抄这份。

## 主回归命令

- 面板 DID：默认使用 `did::att_gt`（Callaway-Sant'Anna），配合 `fixest::feols`
  作 TWFE 对照
- 非面板 OLS：使用 `fixest::feols`；不需要固定效应的简单设定用 `lm()`
- 事件研究图：`did::ggdid()`，不要手工拼 ggplot

## 固定效应

- 双向 FE（同时吸收个体和时间两个维度）默认形式：`feols(y ~ x | id + year)`
- 若涉及行业层级，扩展为 `feols(y ~ x | id + year + industry_id)`
- 固定效应一律写在 `|` 右边，**不在数据里展开成大量 0/1 哑变量**。R 这边还有一层
  实际理由：`feols` 的 `|` 会做去均值，几十个哑变量塞进公式会让内存和速度都难看

## 聚类层级

- 面板 DID 默认聚类于处理层级（通常是州）：`cluster = ~state_id`
- 若研究设计为「州-年对」结构，用 `cluster = ~state_id + year`
- **不使用默认标准误，必须显式声明聚类**

## 各命令不写选项时的默认值不一样（坑三的根因）

「同一项研究里标准误口径不一致」最隐蔽的来源，不是有人写错了哪一条，
而是**几个命令各有一套默认值**，谁都没写错、结果就是不可比。
这一节是唯一需要背下来的地方。

| 命令 | 不写选项时的默认 | 本项目必须写成 |
| --- | --- | --- |
| `att_gt` | 对照组默认 `"nevertreated"`（只用从未处理的）；方差用乘数自助法 | `control_group = "notyettreated"` + 显式 `bstrap = TRUE, biters = 999, clustervars = CLUSTER` |
| `feols` | 见下注——**不写 `cluster` 就不是你要的聚类口径** | `cluster = ~state_id` |
| `lm` | 经典同方差标准误 | 用 `sandwich` + `lmtest` 显式声明，或改走 `feols` |
| `aggte` | 默认 `type = "group"` | 四种聚合各写一次，别靠默认 |

两个推论：

- **`feols` 那一条最容易出事**，因为它不写 `cluster` 时**不报错、也不警告**，
  只是安静地给你一个口径不对的标准误。公式里写了 `| id + year` 看着很规范，
  但固定效应和标准误是两回事——`|` 只吸收固定效应，不动方差。
- **`att_gt` 和 `feols` 并列放进同一张表时，必须让两边方差口径可比。**
  `att_gt` 走乘数自助法，`feols` 走解析聚类，两者机制不同；想让两栏可比，
  除了各自写清楚，还要在正文里说明口径。

> **两条默认值有把握，一条没有。** `att_gt` 的 `control_group` 默认是
> `"nevertreated"`、`aggte` 的默认 `type` 是 `"group"`，这两条我确认过。
> **`feols` 不写 `cluster` 时到底是 iid 还是按第一个固定效应聚类，我没有把握**——
> 记忆里有互相矛盾的说法。本机还没装 R，**这个仓库里一行 R 都没跑过**。
> 等装好 R，跑 `?feols` 看 `vcov` 一节、或 `?vcov.fixest`，核完把这段删掉。
>
> 不管默认是哪个，**本项目的规定都写 `cluster = ~...`** —— 显式写出来就绕开了
> 这条不确定性本身。这也是唯一需要记住的操作。

## 标准误与显著性

- 系数保留 3 位小数，标准误保留 3 位小数（`sprintf("%.3f", ...)`）
- 显著性星号：`* 0.1`、`** 0.05`、`*** 0.01`
- 括号内一律为聚类标准误，不使用默认标准误
- 置信区间默认报 95%

## 结果对象规范

- 所有主回归结果必须存下来，**不靠屏幕输出**。命名格式：`[method]_[sample]`
- 例：`att_gt_full`、`twfe_full`、`att_gt_excl_large`
- 存成 `.rds` 放进 `output/`，供 `07_tables` 批量读出来排版，避免重复运行
- 每个结果对象必须在日志里留下对应的**数据指纹**（`saveRDS` + `tools::md5sum`）——
  这是「这个系数是从哪份数据估出来的」的唯一凭据

## 禁止事项

- 禁止在回归前对样本做未在 `03_clean.R` 声明的筛选
- 禁止在稳健性矩阵中悄悄改变聚类层级（会导致同一张表里不同列的标准误口径不一，无法横向比较）
- 禁止隐藏筛选条件，所有样本筛选必须留痕
- 禁止把 `aggte()` 的输出**手工搬运**成表格数字。要搬运就写代码搬，
  手敲的数字下次重跑就对不上
