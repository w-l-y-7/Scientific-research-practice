# grade-assessment：按论文做 GRADE 证据分级

把文献笔记里的 DOI 变成一份带评分理由的 GRADE 等级表。

## 先搞清楚这个技能在干什么

标准 GRADE 是**按结局指标**评的——同一个干预、「死亡率」和「生活质量」两个结局可以拿到完全不同的等级。

这里做的是**按论文**评。这是教学和写综述场景里的简化做法，代价是**丢掉结局维度**：一篇论文如果主结论强、次要结论弱，这张表只能给一个等级。所以定级时盯住**论文的主结论**，并在评分理由里写清定级依据是哪个结论，别让读者以为整篇论文所有结论都是这个等级。

这个差别要在交付时跟用户说一次。

## 核心原则：信息缺失不等于降级

**这条决定了整个技能有没有用。**

GRADE 的调整逻辑是「没做稳健性检验 → 降级」。但摘要是二手信息，**几乎不会写样本量，更不会写做了哪些稳健性检验**。如果把「摘要没提」当成「没做」来处理，结果是每篇论文都被降一级，整张表全是极低——这不是评价，是噪声。

所以规则是：

- 摘要提到了、且不合格 → **降级**，理由写「摘要显示…」
- 摘要没提到 → **不降级**，在评分理由里写「摘要未提及」，并降低「依据完整度」
- 摘要没提到，但读者需要知道 → 在末尾「无法评估的部分」里点名，建议回去读全文

判断的是**你手上有的证据**，不是**论文本身的全部证据**。两者要分清楚，并在输出里标出来。

## 执行步骤

### 第 0 步：确认入口

看 `literature_notes/summary_table.md` 在不在、里面有没有 DOI。

- **文件不在或没有 DOI** → 停下来问用户。**不要**自己找论文、**不要**编 DOI。
- **有 DOI** → 继续。

### 第 1 步：抓摘要

```powershell
python .claude/skills/grade-assessment/scripts/fetch_abstracts.py literature_notes/summary_table.md -o literature_notes/raw_abstracts.json
```

输出 `literature_notes/raw_abstracts.json`，**机器生成，不要手改**——重跑会整个覆盖。每条包含 DOI、标题、摘要、期刊、年份、第一作者、类型、被引数。

脚本会把「取到但没摘要」和「Crossref 查不到」分开报在末尾。跑完**先看这段统计再往下走**：摘要覆盖率低是常态（IEEE 和很多工作论文不存摘要），但要知道低到什么程度，因为后面的等级可信度取决于它。

### 第 2 步：逐篇评级

读 `raw_abstracts.json`，按下面的规则给每篇定级。记录每一档的判断依据，第 3 步要用。

### 第 3 步：写入分级表

覆盖 `literature_notes/grade_assessment.md`（模板见下）。写完把「无法评估的部分」和整体分布讲给用户听，不能只报一句「分级完成」。

## 评级规则

### 第一步：识别策略定起始等级

| 识别策略 | 起始等级 | 为什么是这个档 |
| --- | --- | --- |
| RCT / 随机田野实验 | 高 | 随机分配直接切断选择偏误，是因果推断的上限 |
| 自然实验 | 高 | 外生冲击近似随机分配 |
| RDD | 中 | 断点附近近似随机，但结论依赖带宽选择和操纵检验 |
| DID | 中 | 依赖平行趋势，而平行趋势假设本身**无法直接检验** |
| IV | 中 | 依赖排他性约束，排他性同样**无法直接检验** |
| 匹配 / 面板固定效应 | 低 | 只能处理可观测混杂和时不变的不可观测混杂 |
| OLS / 相关性 / 描述统计 | 极低 | 排除不了遗漏变量，只能说明相关 |

**识别策略从摘要、标题，必要时从期刊和论文类型推断。** 推不出来就写「未标明」，起始等级按最低档（极低）计——但**这不是判定论文差**，是手上没有依据，必须在评分理由里说明。

注意 RDD/DID/IV 定在中档的理由是**假设不可检验**，不是方法不好。写理由时要说清这一点，否则读者会误以为在贬低准实验方法。

### 第二步：三个维度做调整

每项最多动一级，累计最多降 3 级，**最终等级不能低于极低、不能高于高**。

| 维度 | 降级（最多 −1） | 升级（最多 +1） |
| --- | --- | --- |
| **样本与数据** | 样本量小；单一市场或单一时期；数据来源不可核查；存在明显幸存者偏差 | 多市场、多时期；数据来源和抽样过程交代清楚 |
| **稳健性** | 摘要明说只报主回归；或标题/摘要暗示结论依赖于某个特定设定 | 明说做了多种检验且通过（安慰剂、平行趋势、更换测度、改变样本期） |
| **一致性** | 与同类研究结论**矛盾**，且矛盾无法用样本或方法差异解释 | 与多篇独立研究（不同数据、不同市场）结论一致 |

注意「一致性」要看的是**和谁比**：和同一批数据、同一个作者的系列论文一致，不构成独立验证，不算升级。

### 第三步：标依据完整度

| 完整度 | 含义 |
| --- | --- |
| 高 | 三个调整维度都有依据可判 |
| 中 | 两个维度有依据 |
| 低 | 一个或零个维度有依据；或**这篇根本没取到摘要** |

**完整度低 + 等级高**是最危险的组合——看着漂亮，其实没有依据支撑。这种条目要在输出里显式点出来。

## 输出模板

写入 `literature_notes/grade_assessment.md`，用这个结构：

```markdown
# GRADE 证据分级

> 生成日期：YYYY-MM-DD
> 数据来源：literature_notes/summary_table.md（N 篇）
> 摘要来源：Crossref，M 篇取到摘要，K 篇未取到
> **注意：本表按论文评，非按结局指标评。等级针对论文主结论。**

## 分级结果

| 论文 | 识别策略 | 起始等级 | 调整 | 最终等级 | 依据完整度 | 评分理由 |
| --- | --- | --- | --- | --- | --- | --- |
| 作者 (年份) | DID | 中 | −1 样本 | 低 | 中 | 平行趋势检验充分；样本仅美国单州 1990–2005；摘要未提稳健性 |

## 分布

- 高：N 篇 ｜ 中：N 篇 ｜ 低：N 篇 ｜ 极低：N 篇
- 依据完整度低的条目：列出

## 无法评估的部分

- 逐条列出「摘要未提及、需要读全文才能确认」的事项，写清是缺样本量、缺稳健性检验、还是识别策略都没标
- 没取到摘要的论文单独列

## 对综述写作的提示

- 低和极低等级的结论，正文里写成「证据有限」或「有待进一步检验」，不要写成「已证实」
- 高等级但依据完整度低的条目，引用前回头核对全文
```

## 红线

- **不编造识别策略、样本量、稳健性检验。** 摘要没写就写「摘要未提及」，让它缺着。
- 查不到的 DOI 不要跳过不提，要在「无法评估的部分」里列出来。
- 不因为「等级看起来分布不均衡」就回头调等级去凑一个好分布。
- 不手改 `raw_abstracts.json`。
- 引用被引数时注意口径：Crossref 的 `cited_by` 普遍低于 Google Scholar，**不要**拿它跟 Scholar 的数字比，也不要单独用它升降级。

## 坑

1. **摘要覆盖率低是常态。** 金融经济领域，Elsevier / Springer / Wiley 系多数有摘要，IEEE 和大量工作论文没有。跑完先看统计，覆盖率三成不奇怪，别以为是脚本坏了。
2. **Crossref 的摘要带 JATS 标签。** 原始值形如 `<jats:p>We study…</jats:p>`，脚本里的 `clean_abstract()` 已经剥掉，但如果你自己拿接口数据，记得处理，否则会看到一堆尖括号。
3. **Crossref 偶尔 429。** 脚本内建了指数退避，三次还失败就跳过并报在网络失败里，重跑即可。
4. **预印本和正式版会各占一条。** 同一篇论文 arXiv 版和期刊版 DOI 不同，两边都会被评一次。定级前先看是不是同一篇，是的话合并处理。
5. **`raw_abstracts.json` 每次整个重写。** 改了也白改。
6. **摘要短不代表论文差。** 有些期刊摘要限 150 词，信息量天然少，这会压低「依据完整度」而不该压低等级。
