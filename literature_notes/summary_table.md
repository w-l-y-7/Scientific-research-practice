# 文献笔记

这个是引用流水线的**唯一输入端**。要改作者名、补页码、加文献，都改这个文件，然后重跑流水线。

`citations/` 下面那四个文件（`doi_list.txt`、`raw.bib`、`references.bib`、`validation.json`）
都是机器生成的，手改会在下次重跑时被覆盖。

## 怎么用

在下面的表里加行，一行一篇。**只要 DOI 写对，其余字段由 Crossref 自动补全**，
所以标题写个大概就行，写成什么样都不影响结果——抽 DOI 用的是正则，不看格式。

DOI 支持三种写法，随便哪种：

- 裸写：`10.1109/IROS60139.2025.11246190`
- 带链接：`https://doi.org/10.1038/s41586-020-2649-2`
- 带前缀：`doi:10.1145/3292500.3330701`

跑法见 `.claude/skills/citation-management/SKILL.md`，或者直接说「跑一下引用流水线」。
